# Haider Fahim — Complete Website

This package contains the complete portable website, including the latest Technology Education text, portrait, styles, JavaScript, favicon and all contact/social links.

## Run immediately
1. Extract the ZIP.
2. Open the Haider_Fahim_Website folder.
3. Double-click index.html to open it in a modern browser.

No installation, build process, database or API keys are required.

## Optional local web server
If Python 3 is installed, open Terminal in this folder and run:

    python3 -m http.server 8000 --bind 127.0.0.1

On Windows, you can use:

    py -m http.server 8000 --bind 127.0.0.1

Open http://localhost:8000 in your browser. Stop the server with Ctrl+C.

## Files
- index.html — all page content, navigation and contact links
- style.css — complete responsive design, including the 3D header and footer
- app.js — project cards, filters, dialogs, skills, mobile menu and animations
- haider-fahim.webp — optimized portrait
- favicon.svg — HF browser icon

## Edit and host
Edit the files in any text editor, such as VS Code. Project descriptions and skill groups are in app.js; other text is in index.html. Keep the files together so relative links continue to work.

To host elsewhere, upload all five website files to your static hosting provider's public web directory. README.md is optional. Hosting configuration and credentials are not needed to run this portable copy. The canonical and Open Graph URL in index.html currently point to the published ChatGPT Site; update these if you use another public domain.

Email, WhatsApp, GitHub, LinkedIn and Facebook links open their respective services and require an internet connection. All website assets are included locally.
